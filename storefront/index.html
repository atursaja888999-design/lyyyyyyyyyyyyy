Tidak untuk versi awal. Anda cukup memasukkan data akun game dan nomor WhatsApp saat checkout.

Bagaimana cara mengecek status pesanan?

Gunakan nomor invoice yang diberikan setelah checkout pada fitur cek pesanan di halaman ini.

Apakah transaksi langsung masuk ke admin?

Ya. Saat sistem order sudah aktif, setiap order akan otomatis masuk ke panel admin untuk diproses.
